# FCX 隐私说明

本文说明公开仓库中的 FCX 用户脚本和本地求解后端会处理哪些数据、数据存放在哪里，以及用户如何删除数据。远程 API 服务端和小程序不在本仓库中，其线上隐私政策应由对应服务另行公布。

## 数据最小化原则

FCX 区分本地数据与远程账号数据：

- SBC 球员池和求解请求只发送到用户本机。
- 不上传 EA Cookie 或 EA Token。
- 不动态下载或执行远程业务代码。
- 任务历史默认只保存在浏览器本地。
- 远程控制只同步必要状态和声明式目录。

## 本地处理的数据

### SBC 和球员

为求解 SBC，脚本会读取：

- 俱乐部和 SBC 仓库球员实例。
- 球员总评、卡型、俱乐部、联赛、国家、位置和特殊组。
- 当前激活阵容实例。
- 手动锁定卡型。
- 进化状态。
- SBC 挑战要求。

这些数据用于浏览器候选过滤，并发送到 `127.0.0.1` 本地后端求解。公开仓库中的脚本不会把完整球员池发送到远程 FCX API。

### 设置与保护

以下信息通常保存在 EA 页面站点存储：

- SBC 总评、价格和排除规则。
- 球员锁定和保护配置。
- 开包、挑选、永动机和进化设置。
- 本地后端端口。

清除 EA 网站数据会删除这些设置。

### 价格缓存和任务历史

浏览器 IndexedDB 可能保存球员价格缓存、最近任务历史和总结。任务历史按 persona 隔离，默认最多 100 条且最长 30 天，不上传远程服务端。

### 本地后端日志

本地后端可能在用户电脑生成求解日志，用于诊断约束和求解状态。日志目录已被 Git 忽略；公开分享前应检查并脱敏。

## 远程账号与小程序

用户主动注册或登录时，脚本会向 FCX 远程 API 发送账号请求。浏览器端可能处理：

- 用户名、密码和可选邮箱。
- Access Token、Refresh Token。
- 设备 ID、设备名称和客户端版本。
- 任务类型、状态、目录摘要和错误原因。
- 用户主动启用的收菜记录和通知配置。

密码只用于登录或注册请求，不持久化。Token 和设备信息保存在 Tampermonkey GM 存储，不写入 EA 页面 `localStorage`。不要导出或分享包含 FCX 数据的 Tampermonkey 备份。

远程控制不应上传：

- EA Cookie 或 EA Token。
- 完整俱乐部球员池。
- 完整价格缓存。
- 手动锁定球员名单。
- 本地求解请求正文。

## 外部服务

根据用户启用的功能，脚本可能访问：

- EA Ultimate Team Web App API。
- FCX 主站和远程账号 API。
- 版本和流程静态 JSON。
- 用户选择的价格来源。
- 用户主动配置的 ntfy 通知服务。

Tampermonkey 元数据中的 `@connect` 列表是脚本可访问域名的技术上限。新增域名必须经过代码审查并更新隐私和安全文档。

## 数据保留与删除

用户可以通过以下方式删除本地数据：

- 在 FCX 页面清空任务历史。
- 清除 EA 网站的站点数据。
- 清除 Tampermonkey 中 FCX 的存储。
- 删除或停用 FCX 用户脚本。
- 删除本地后端日志目录。

清除 Tampermonkey 数据会退出 FCX 账号并删除本地设备会话信息，但不会自动删除远程账号。远程账号删除能力以线上服务实际提供的功能为准。

## 日志和问题反馈

提交公开 Issue 前请删除：

- Token、Cookie 和 Authorization 请求头。
- 用户名、邮箱和 persona ID。
- 完整球员池。
- ntfy Topic。
- 服务器地址中可能包含的个人参数。

优先复制 FCX 提供的脱敏诊断信息，不要导出整个浏览器网络日志。

## 变更

新增数据类型、远程域名、存储位置或远程功能时，必须同步更新本文。重大隐私边界变化应在版本更新说明中明确提示。
